Rendering permission does not establish permission for training or evaluating AI. This file records dependency provenance and the current unresolved decision; it is not a new legal assessment. Do not infer AI-evaluation clearance from the current rendering demo.

The authored landscape, character and vegetation binaries are held privately with the deployment. Rebuilding the same world from this repository requires those dependencies and the documented authoring sequence; the repository is not a complete photorealistic content distribution.

### Character selection thumbnails

`web/public/portraits/rocketbox-*.jpg` contains small neutral-light renders of the eleven
approved Rocketbox characters. They contain no source meshes, source
textures, private scenario locations or EXIF metadata. The original character
licenses above still govern their underlying assets. The briefing displays no
missing-person portrait.
